        The real secret of RMI:

        When you call  service.doSomething(arg)

        1. Your code calls a stub (a Proxy object in the same JVM)
        2. The stub serializes the method name + args into bytes
        3. Sends them over a TCP connection to port 1100
        4. The server deserializes, finds the real object, calls it
        5. Serializes the return value back the same way
        6. Your code gets the result — looks like a local call!

        That's it. That's the whole trick.
        No magic. Just bytes on a socket.

        (The callback is the same thing in reverse:
         the SERVER calls YOU via your exported stub.)
